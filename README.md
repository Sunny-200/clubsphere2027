## Overview

**CLUB_SPHERE** is a comprehensive developer toolkit crafted to accelerate the development of community-centric web applications.

It provides:

- Modular architecture  
- Centralized UI configurations  
- Role-based access control  
- Seamless API integrations  

This enables developers to build **scalable and cohesive platforms effortlessly.**

### Why CLUB_SPHERE?

This project aims to simplify the creation of engaging, role-aware community platforms. Its core features include:

- **UI Consistency:** Centralized component configurations ensure a cohesive visual style across your app.  
- **Secure Authentication:** Built-in auth controllers and middleware support secure, role-based user access.  
- **Modular Components:** Reusable UI elements like modals, navigation, and club cards streamline development.  
- **API Management:** Well-defined routes for clubs, events, and user data facilitate robust backend interactions.  
- **Custom Hooks:** Simplify data fetching and state management for clubs, calendar events, and user sessions.  
- **Developer-Friendly Workflow:** Tailwind CSS, ESLint, and Next.js configs optimize your development experience.

## Installation

Build **CLUB_SPHERE** locally with these steps:

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Keerthi-vassan/CLUB_SPHERE
```

### 2️⃣ Navigate to the project directory

```bash
cd CLUB_SPHERE
```

### 3️⃣ Install dependencies

```bash
npm install
```
